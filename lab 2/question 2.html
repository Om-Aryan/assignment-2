GitHub is a web-based platform built on top of Git.
the open-source version control system that provides hosting, collaboration and version control for software projects and other types of files.
It allows developers and other professionals to create and manage code repositories, track changes, and work together on projects in a distributed manner, even from different locations.

LeetCode is an online platform for software engineers and aspiring developers to practice coding and prepare for technical interviews.
It features a vast collection of coding and algorithmic problems, ranging in difficulty, covering concepts like data structures and algorithms and provides an online editor for users to solve these problems in their preferred programming language.

Poki is a free online gaming platform offering instant access to a vast library of games directly in your web browser, without requiring downloads or logins.
The platform features a wide variety of games, including action, puzzle, strategy, educational and multiplayer options and is accessible on desktop, tablet, and mobile devices.
